# Assistant files

Plans and notes from Grok or Claude live here. They are not part of the lesson.

This folder is the repo's home for assistant files, in the same spirit as `.superpowers`: one hidden place, split by tool, kept out of the student path.

Start the lesson at [docs/index.md](../docs/index.md). Commands are in [runbook.md](../runbook.md).

| Folder | What goes here |
| --- | --- |
| `grok/` | Plans and notes from Grok sessions |
| `claude/` | Plans and notes from Claude sessions |
